# Northwing 0.3.1 Stability Audit

Date: 2026-08-10
Branch: `fix/northwing-0.3.1-stability`
Baseline: `b10c136d391a6339e0efbd45bff8a44d2f9d1cc8` (`northwing-v0.3.0`)

## Baseline method

The audit traces each visible feature from `desktop/frontend/src/main.tsx` through the Northwing shell and bridge to its Go or Wails implementation. Unit and browser tests are treated as supporting evidence only when they exercise that production path. Source-string guards remain useful as secondary release checks.

The initial checkout was clean and matched `origin/main-v2`. Frontend dependency installation and `pnpm typecheck` succeeded. The complete frontend test command is blocked in the current Linux sandbox because the `tsx` CLI cannot create its IPC Unix socket (`listen EPERM`). Direct `node --import tsx` test execution remains available. The current runtime does not contain Go, Wails, PowerShell, Windows, Authenticode, or Defender, so those gates require GitHub-hosted or controlled Windows runners.

## Release decision at baseline

The 0.3.0 baseline is not eligible for a stable 0.3.1 tag. P0 and P1 findings remain open, signed artifacts are unavailable, the Defender result is unresolved, and the required Windows-native evidence has not been produced.
